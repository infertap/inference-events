FINDINGS:
- three ZMQ frames [topic, 8-byte big-endian seq, msgpack]; the batch is [ts, events, attn_dp_rank]; events are maps with "type"
- a repeated prefix produces no second BlockStored: the radix cache records a store only when it creates a node
- a node split records nothing; the diverging tail arrives as one BlockStored whose parent is a page of the split node
- cache_salt rides the event, once, as a string; a salted request stores its whole prefix again under its own namespace
- BlockStored carries block_hashes, parent_block_hash, token_ids, block_size, lora_id (null), medium, and cache_salt where set;
  session_id is omitted when unset (msgspec omit_defaults)
- BlockRemoved carries block_hashes and medium; AllBlocksCleared carries nothing
- block_size is the page's own token count: a request's final partial page is its own event
- /flush_cache emits one AllBlocksCleared in the batch of the next scheduler step
- the replay ROUTER answers (seq, payload) pairs from the requested seq and ends with the END_SEQ marker
- single A40: tensor parallelism 1, one rank; attn_dp_rank is always 0
